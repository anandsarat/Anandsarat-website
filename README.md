# Anand Sarat — Executive Leadership Facilitator Website

## Included Files
- `index.html` — Production HTML5 page with SEO metadata, Open Graph tags, and WCAG 2.2 AA accessibility attributes
- `css/styles.css` — Custom Çelebi Aviation Blue theme rules (`#004B87`) and responsive grid styles
- `js/main.js` — Interactive track filters, accessible mobile navigation, modern Clipboard API, and contact form handler
- `assets/images/` — Web-optimized WebP and JPEG studio portraits (`anand-hero-portrait` and `anand-advisory-laptop`)

## Quick Deployment Options
1. **Netlify / Vercel (Recommended — Free & Automatic SSL):**
   - Extract the ZIP folder and drag `anand-sarat-website` onto [app.netlify.com/drop](https://app.netlify.com/drop).
   - Connect your custom GoDaddy domain (`www.yourdomain.com`) under Domain Settings.
2. **cPanel / Traditional Web Hosting:**
   - Upload all contents of `anand-sarat-website/` directly into your `public_html` directory.
3. **Connecting Formspree (Optional):**
   - Create a free form at [formspree.io](https://formspree.io) and paste your endpoint URL into `data-endpoint=""` inside `<form id="contactForm">` in `index.html`.
